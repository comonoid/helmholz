## КЛЮЧИ, ДЕЙСТВУЮЩИЕ СЕЙЧАС (краткая выжимка)

Полная история ключей с обоснованиями — в архивных §-записях и `--help`
инструментов. Действующие режимы:

    xsweep nmu= lev=     развёртка по ординатам
    xthin= xsemin=       пороги щепок/вырожденных элементов (1e-2)
    xmatrho              материальные альбедо (атрибуция по близости)
    xit= xtol= xreltol=  потолок итераций, абсолютный/относительный допуск
    xbounce=             лестница отскоков + замыкание хвоста (5 — рабочее)
    xcoarse=             огрубление приёмников на кусках (10 — рабочее)
    xframe lit res= ss2 cam=   кадр; ceil= poly= — потолки растра
    xwarm=               стенд инкрементности (двухкадровый)
    walk / path=         режимы сбора (walk — продакшн, path — за ключом)
    adapt= lpceil= lppol= amode= cdelta=   адаптивные этажи детальности
    ksf=                 доля зеркального хопа (T4; fail-closed)
    xgloss               аналитический Фонг-блик в растре

Частые НЕГАТИВНЫЕ КОНТРОЛИ: xnolim, xnomaxp, xmatfar, xnopiece, xscramble,
xgloss0, memoscramble, nomemo. НК обязан провалиться ПРЕДСКАЗАННЫМ образом.
