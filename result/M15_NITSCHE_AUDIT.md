## 1. ФОРМА. ВЫВОД, А НЕ ЦИТАТА

Обозначения: `Γ` — локус разреза (фасетированная окружность, ТА ЖЕ, по которой
режется базис); `n` — единичная нормаль Γ, наружу от рассеивателя;
`[v] = v⁺ − v⁻` (внешнее минус внутреннее, ровно как в снятых коллокационных
строках); `{v} = (v⁺+v⁻)/2`. Форма БИЛИНЕЙНАЯ (тестовая функция НЕ сопрягается)
— как во всей 2D-сборке.

**Ключевое тождество (доказано, не постулировано).** Носители компактны, φ ∈ C¹,
значит на краю носителя граничного члена нет, и теорема Грина по каждой из двух
областей даёт ТОЧНО:

```
Strong_ij ≡ ∫ B_i (Δ + k²) B_j  =  − a_broken(B_i,B_j) − ∮_Γ ( [B_i]{∂ₙB_j} + {B_i}[∂ₙB_j] )
a_broken(u,v) = ∫ (∇u·∇v − k² u v)          (симметрична)
```

То есть **сильная форма УЖЕ содержит слабую, проинтегрированную по частям
аналитически; не хватает ровно двух поверхностных членов, и оба измеримы.**
Переписывать объёмные интегралы не нужно — это главный вывод аудита по объёму
работ: Нитше стоит ОДИН новый интегральный примитив (линейный интеграл вдоль
фасета), а не пересборку оператора.

Стандартная (симметричная) форма Нитше для задачи передачи `[u]=0`, `[∂ₙu]=0`:

```
a_N(u,v) = a_broken(u,v) − ∮_Γ ( {∂ₙu}[v] + {∂ₙv}[u] ) + β ∮_Γ [u][v]
```

Подстановка тождества выше даёт **A = −a_N** через уже написанный `entry()`:

```
A_ij = Strong_ij + (2 α_i β_j + β_i α_j)·T1_j + β_i α_j·T1_i − β_pen·α_i α_j·T0
T0  = ∮_Γ B_i B_j ds        T1_j = ∮_Γ B_i (n·∇B_j) ds        T1_i = ∮_Γ B_j (n·∇B_i) ds
```

где для КАЖДОЙ функции пара коэффициентов следа `([v] = α·v|_Γ, {v} = β·v|_Γ)`:
разрезанная со стороной σ (σ=+1 снаружи, −1 внутри) даёт `(α,β) = (σ, 1/2)`
(функция тождественно ноль по другую сторону), неразрезанная — `(0, 1)`.

Общий знак строки безразличен: у операторных строк правая часть ТОЖДЕСТВЕННО
НОЛЬ, а блок DtN — отдельные строки. Знак внутри строки — нет, и он проверяется
пунктом F-S ниже.

### Три свойства, которые из этого следуют и которые надо проверять, а не верить
1. **Согласованность (consistency) даром.** Все три добавленных члена
   пропорциональны `[u]` или `[∂ₙu]`, а истинное решение непрерывно и по `u`, и
   по `∂ₙu` ⇒ они на нём обращаются в ноль. Правая часть НЕ МЕНЯЕТСЯ.
2. **Ядро ломается ДАЖЕ БЕЗ ШТРАФА.** У `d = αB_in + βB_out`, `α≠β`, скачок
   ненулевой ⇒ члены `T1` дают ненулевую строку. Значит `β_pen` отвечает не за
   само существование ограничения, а за его МАСШТАБ. Отсюда и ожидание плато.
3. **СИММЕТРИЯ.** `a_N` симметрична по построению, а `Strong_ij` для
   разрезанных пар — НЕТ (интегрирование по частям по каждой стороне оставляет
   несократившийся поверхностный член). Значит собранный операторный блок обязан
   стать симметричным ПОСЛЕ добавления членов Нитше и быть несимметричным ДО.
   Это независимый свидетель правильности вывода и знаков, не стоящий ни одного
   нового прогона. Оговорка, без которой тест был бы неверен: `k²` в
   `entry()` — это `|k_j|²` несущей, а на общей области пары обе несущие лежат в
   ОДНОЙ среде (пары из разных сред имеют пустое пересечение носителей ⇒ 0), то
   есть `k²`-член тоже симметричен.

### Что появляется в матрице и чего там не было
Пары «внутренняя × внешняя» сейчас дают РОВНО НОЛЬ (`region_int` видит
непересекающиеся области). После Нитше они связаны через `T0`/`T1`. **Связи
между сторонами разреза в матрице до сих пор не существовало вовсе** — это и
есть содержательная разница с коллокацией, где связь была, но через выборку.

## 2. ШТРАФНОЙ КОЭФФИЦИЕНТ: ОЦЕНКА, А НЕ СВИП

Требование к `β_pen` — чтобы штрафной член ДОМИНИРОВАЛ согласующие члены:
`β ∮[v]² ≳ 2|∮{∂ₙv}[v]|`, откуда `β ≳ sup ‖∂ₙv‖_{L²(Γ∩K)} / ‖v‖_{L²(Γ∩K)}`.
Для несущего базиса `v = env·e^{ik·x}` и `|v| = |env|` (модуль несущей равен 1,
осцилляция след в L² не портит), поэтому

```
‖∂ₙv‖ ≤ |n·k|·‖v‖ + ‖∂ₙ env‖ ≤ ( k_max + C_inv/W ) ‖v‖
```

`C_inv` — константа обратного неравенства в L² для КВАДРАТИЧНОГО куска на
интервале длины `W`. Считается точно: на `[−1,1]` максимум `‖p′‖/‖p‖` по
`p ∈ P₂` достигается на `p = t²−1/3` и равен `√15 = 3.873`; масштабирование на
длину `W` даёт `2·3.873/W = 7.75/W`. Берём кусок (не весь носитель) — это
консервативно, то есть оценка СНИЗУ на `β` завышена, что и требуется.

```
β_pen = γ · ( k_max + 7.75/W ),      γ ≥ 1,   оценка γ = 1
```

**ЧИСЛО ДО ПРОГОНА** для конфигурации гейта (λ=1, n=1.5, k_max = 1.5·2π = 9.425,
W = λ/2): `β_pen = 9.425 + 15.50 = 24.9 λ⁻¹` при γ=1.
Для справки: классическая безосцилляционная оценка `C_inv/W` дала бы 15.5, то
есть **ровно тот же порядок** — при `kW = π` осцилляционная поправка меняет
оценку в 1.6 раза, а не на порядок. Расхождение станет существенным при `W ≫ λ`
(там `β ≈ k`), и это записанное здесь предсказание на будущее, а не на этот шаг.

### Приёмка по γ (то, ради чего этот шаг вообще затевается)
Свип `γ ∈ {0, 1/8, 1/4, 1/2, 1, 2, 4, 8, 32}` печатается КРИВОЙ.

- **ПЛАТО (приёмка):** при γ ∈ [1, 8] ошибка меняется на ≤10% относительно
  значения при γ=1; удвоение (γ=2) и уполовинивание (γ=0.5) меняют ответ на
  ≤10%.
- **ДОПУСТИМЫЙ ВТОРОЙ ИСХОД, названный заранее:** если деградация начинается
  ниже γ=1, а выше — плато, это НЕ ручка: оценка есть граница СНИЗУ, и её
  активность — подтверждение вывода, а не подгонка. Условие: граница должна
  сойтись с предсказанной ВЕЛИЧИНОЙ 24.9 λ⁻¹ в пределах ×3.
- **ПРОВАЛ ШАГА:** ошибка имеет МИНИМУМ по γ (яма), как у коллокации по числу
  точек. Тогда Нитше — та же ручка под другим именем, и об этом пишется прямо.
- **ПРОВАЛ ДРУГОГО РОДА (подпись артефакта, ловится тем же свипом):** ответ
  совпадает до 5-го знака на ДВУХ ДЕКАДАХ по γ. Это не плато, а признак того,
  что член вообще не доходит до матрицы (ровно так свип веса DtN 1…10⁴ показал
  совместность системы, а не безразличие к весу). **Плато обязано шевелиться в
  3–4 знаке.**

## 3. ФАЛЬСИФИКАТОРЫ (порог ДО прогона)

- **F-N1 (ГЛАВНЫЙ). Вакуум с ПРИНУДИТЕЛЬНО ВКЛЮЧЁННЫМ разрезом.** n=1 по обе
  стороны, но геометрия разреза включена (сейчас `straddles()` её глушит).
  Точное решение — падающая плоская волна, лежащая в пролёте ТОЧНО и с обеих
  сторон с ОДИНАКОВЫМ коэффициентом ⇒ все скачки нулевые.
  Измерено ДО Нитше: **0.197 / 0.257 / 0.405** при ND = 2/4/8; без разреза
  **0.0166 / 0.0112 / 0.0073**.
  **ПРЕДСКАЗАНИЕ: 0.007–0.020 при всех трёх ND, и тренд по ND снова падающий.**
  Порог провала: > 0.05 ⇒ Нитше скачок не зажал, шаг провален.
  Это готовый негативный контроль с ИЗВЕСТНЫМ заранее правильным ответом, и он
  ломает ОДНУ сторону сравнения (постановку), а не обе (артефакт 16).
- **F-N2. Вакуум с ВЫКЛЮЧЕННЫМ разрезом.** Член Нитше тождественно ноль (нет
  разрезанных функций). ПРЕДСКАЗАНИЕ: воспроизводит 0.0073–0.0166 **до всех
  знаков, которые печатались раньше**. Любое отличие = задет код, который трогать
  было не надо.
- **F-N3. Симметрия операторного блока.** `max|A_ij − A_ji| / max|A_ij|`
  ПРЕДСКАЗАНИЕ: до Нитше — O(1) на разрезанных парах (≥1e-2), после — ≤1e-10.
  Провал = знаки в §1 выведены неверно.
- **F-N4. Согласованность на известном векторе.** Вакуум + принудительный
  разрез, подставляем ТОЧНЫЙ вектор плоской волны (равные коэффициенты по обе
  стороны, разбиение единицы /16). ПРЕДСКАЗАНИЕ: `|Ac|` остаётся на уровне
  гейта D1, ≤1e-4 (измерено 5.2e-5 без разреза). Рост на порядки = член Нитше
  НЕ согласован, то есть портит правильный ответ.
- **F-N5 (A5, архитектурный). Ядро обязано лежать в нулевом поле.**
  `d = c_LSQR − c_точное` в вакууме с разрезом: сейчас `|Ad|/(|A||d|) = 8.4e-7`
  при поле от `d` 0.41/0.35/0.31/0.28. ПРЕДСКАЗАНИЕ: поле от `d` ≤ 0.03.
  Это единственное измерение, которое отвечает на вопрос PLAN A5, а не на
  вопрос «стало ли лучше».
- **F-N6 (точность примитива).** Линейные интегралы против НЕЗАВИСИМОГО
  свидетеля: адаптивная квадратура (Гаусс–Лежандр с удвоением панелей) при
  умеренном `kW ≤ 4` — совпадение ≤1e-12 от натурального масштаба; аддитивность
  разбиения фасета пополам — ≤1e-14; строгий ноль, когда носители не встречают
  Γ. При больших `kW` квадратура свидетелем быть не может (урок M9a), поэтому
  там работает только аддитивность.
- **F-N7 (геометрия Γ одна и та же).** Вершины многоугольника, по рёбрам
  которого берутся интегралы Нитше, обязаны лежать НА полуплоскостях, по которым
  режется базис: `|v·nᵢ − cᵢ| ≤ 1e-15` для двух смежных фасетов и `< 0` для
  остальных. Если Γ интегрирования и Γ разреза разъедутся, скачок будет мериться
  там, где функция непрерывна, и всё измерение станет пустым.

## 4. НЕГАТИВНЫЕ КОНТРОЛИ (провал ПРЕДСКАЗАН)

- **NC-N1 — перевёрнутый знак скачка** (`α → −α`, то есть `[·] = внутреннее −
  внешнее` только в членах Нитше, эталон не трогаем). Согласующие члены меняют
  знак, штрафной — нет ⇒ форма перестаёт быть `a_N`. ПРЕДСКАЗАНИЕ: ≥0.3, то
  есть ХУЖЕ, чем вовсе без Нитше. Ломается ОДНА сторона.
- **NC-N2 — только штраф, без согласующих членов** (`T1` выброшены).
  Тогда `[u]` зажат, а `[∂ₙu]` не ограничен НИЧЕМ — сильная форма его не видит.
  ПРЕДСКАЗАНИЕ: заметно хуже полного Нитше (≥2×), но лучше отсутствия члена.
  Это измерение того, ЧТО ИМЕННО несут согласующие члены, а не проверка «стало
  лучше».
- **NC-N3 — коллокация в том же бинаре** (старый путь остаётся под явным
  ключом). Нужен, чтобы сравнение «яма против плато» было снято ОДНИМ кодом на
  ОДНОЙ конфигурации, а не против чисел из прошлой сессии.
- **ЗАПРЕЩЁННЫЙ КОНТРОЛЬ:** «нулевой контраст с выключенным разрезом» как
  доказательство работы Нитше — там член тождественно ноль, контроль
  ВЫРОЖДЕН (см. NC-F плана). Он идёт как F-N2 (проверка неповреждения), не как
  зелёный.

## 5. ПРЕДСКАЗАНИЕ ПО ГЕЙТУ D2 (чтобы его нельзя было открыть задним числом)

Конфигурация сравнения — та же, на которой снят свип коллокации: цилиндр n=1.5,
`W=λ/2`, `ND=8`, 32 фасета, окно `r/a = 1.5` (окно НЕПОДВИЖНО, NC1 из M11).

**ПРЕДСКАЗАНИЕ: 8–20%.** Обоснование, всё из уже измеренного:
ND=8 при `W=λ/2` вдвое ниже закона `3+20·W/λ = 13` (F-II); перекос
столбцов/строк ~2 (находка B аудита среза); фасетирование среды 32 фасета —
6.4e-4 (D2-2), пренебрежимо; остаток — представимость.
**То есть гейт D2 (5%) на ЭТОЙ конфигурации не ожидается, и это сказано ДО.**
По честному полу §8 SLICE_PLAN исход 8–20% попадает в «измерено, гейт НЕ взят»
(5–15%) или в «провал шага» (>15%) — разбирается по факту, без сдвига порога.
Что здесь МЕРЯЕТСЯ на самом деле — не гейт, а три вещи: F-N1 (вакуум с разрезом
починен), F-N5 (ядро в нулевом поле) и наличие ПЛАТО по γ. Гейт D2 — следующий
шаг, и он про ND и R/W, а не про разрез.

## 6. ЧЕГО ЭТОТ ШАГ НЕ ПОКАЖЕТ

- **Не показывает поведение при `W ≫ λ`.** Отношение «член Нитше / объёмный
  член» ~ `γ/(kW)`, то есть при крупных элементах штраф относительно слабеет.
  Конфигурация среза `W=λ/2` — самая благоприятная для Нитше; это записано ДО.
- **Не показывает малые срезы (slivers).** У элемента, у которого одна сторона —
  тонкая долька, столбец почти нулевой, а строка после уравновешивания
  нормируется на почти-ноль. В cut-FEM это лечат ghost penalty; здесь min-norm
  LSQR должен это стерпеть, но проверка одна: печатается min/max нормы строки до
  уравновешивания. Порог тревоги — отношение < 1e-10.
- **Не показывает кривой разрез.** Γ фасетирован, как и раньше; правило M14 [3]
  действует, ничего нового не измеряется.
- **Не показывает 3D.** Там `∮` становится интегралом по многоугольной грани —
  та же теорема, другой код.
