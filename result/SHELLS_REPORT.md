# Вопрос 3: диадические оболочки — отчёт (2026-07-25)

Инструмент: `tools/carrier_shell.c`, ccheck CLEAN.

## Правило, которое проверялось
Уровень `j` имеет ширину `W_j = W₀·2^j`. Оболочка `j` покрывает расстояния
`R ∈ [a_j, 2a_j)` с `a_j = W_j/ε`. Так как `W_{j+1} = 2W_j`, то `a_{j+1} = 2a_j`
— **оболочки диадические, каждое удвоение расстояния = один уровень грубее**.
Членство по центру элемента, расширенное на `MARGIN = 2` элемента с каждой
стороны, чтобы разбиение единицы (четыре перекрывающихся сдвига) выполнялось по
всей оболочке, а не проваливалось на её краях.

## [2] ГЛАВНОЕ: вырожденность отслеживает ПЕРЕКРЫТИЕ, а не глубину
Доля перекрытия = `2·(MARGIN+2)·W / (W/ε) = 2·(MARGIN+2)·ε`.

| ε | перекрытие | оболочек | dim | **ранг/dim** |
|---|---|---|---|---|
| 1/4 | 2.00 | 13 / 20 / 27 | 338 / 556 / 768 | **0.70 / 0.72 / 0.72** |
| 1/8 | 1.00 | 11 / 18 / 24 | 442 / 766 / 1082 | **0.82 / 0.82 / 0.83** |
| 1/16 | 0.50 | 10 / 16 / 23 | 660 / 1194 / 1726 | **0.90 / 0.90 / 0.90** |
| 1/32 | 0.25 | 8 / 15 / 22 | 1052 / 2010 / 2972 | **0.95 / 0.95 / 0.94** |

**Доля ранга постоянна внутри каждого ε при росте числа оболочек с 8 до 27, и
меняется ТОЛЬКО с перекрытием.** Избыточность `1 − ранг/dim` = 30% / 18% / 10% /
5% при перекрытии 2.0 / 1.0 / 0.5 / 0.25 — то есть **линейна по перекрытию и не
зависит от глубины лестницы**.

Это отвечает на главное опасение вопроса 3 положительно: **лестницу можно
наращивать сколь угодно глубоко**, избыточность от этого не растёт. Прежний
провал (cond 1e10 при 27 уровнях, точность разрушена) был не следствием глубины,
а следствием конструкции: при ε=1/4 полоса шириной 2W против носителя 4W плюс
поля ±2W — уровни перекрывались почти полностью.

NB о метрике: `cond` здесь ~1e16 ВЕЗДЕ и бесполезен — базис вырожден ТОЧНО по
построению (рефайнабельность φ плюс найквистова мода), наименьшее сингулярное
число машинный ноль всегда. Правильная метрика — **доля ранга**, и она
информативна. Это подтверждает пометку к вопросу 7: число обусловленности для
этого базиса смысла не имеет.

## [3] Движение камеры: доля изменившихся элементов (PLAN A2)
Домен 10⁵λ, ε=1/16, `R_near = W₀/ε` — внутренний радиус первой оболочки.

| сдвиг/λ | сдвиг/R_near | изменилось | доля |
|---|---|---|---|
| 0.125 | 0.0625 | 28 | 0.024 |
| 0.25 | 0.125 | 36 | 0.030 |
| 0.5 | 0.25 | 56 | 0.047 |
| 1 | 0.5 | 100 | 0.084 |
| 2 | 1.0 | 192 | 0.161 |
| 4 | 2.0 | 380 | 0.318 |

При `сдвиг/R_near ≳ 0.25` доля **линейна**: коэффициент 0.19 / 0.17 / 0.16 /
0.16 — то есть `доля ≈ 0.16 · сдвиг/R_near`. Ниже этого есть **пол ~2%**:
элементы, сидящие вплотную к границам оболочек, переключаются при любом сколь
угодно малом сдвиге (узловая решётка фиксирована в пространстве).

Практический перевод: шаг 1 см в комнате с `R_near ≈ 0.5 м` даёт
`сдвиг/R_near = 0.02`, то есть попадает в пол — **порядка 2-3% элементов за
кадр**. Утверждение A2 подтверждено количественно.

## Что этот замер НЕ говорит
- Это **счёт и обусловленность, а не решение**. Сколько проходов поправки
  нужно на изменившиеся элементы — вопрос M11, и он требует решателя.
- 1D. В 2D/3D оболочки — кольца и сферические слои, число элементов в оболочке
  растёт, но доля изменившихся должна вести себя так же (она геометрическая).
  Проверять в M11.
- Пол в 2% — артефакт фиксированной узловой решётки. Возможно снимается
  привязкой решётки к камере, но тогда ломается переиспользование записей
  матрицы (они зависят от пары элементов, а не от камеры). Размен не изучен.
