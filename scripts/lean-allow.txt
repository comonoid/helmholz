# `scripts/lean.sh` ищет мёртвый код по живому набору (src/, tools/, tests/) и
# потому «не видит» двух законных случаев:
#   1) публичный API общего слоя, который зовёт АРХИВНАЯ линия (archive/geom/) —
#      она не собирается из корневого Makefile, но остаётся эталоном и вернётся
#      при паритете (см. CLAUDE.md: старый путь — ПРОДЮСЕР и ЭТАЛОН);
#   2) точки входа внешних фреймворков (harness для CBMC, LLVMFuzzerTestOneInput
#      для libFuzzer) — их зовёт инструмент, а не наш код.
#
# Формат: ИМЯ — причина (одна строка; читается человеком, машиной не парсится).
# Правило: сюда попадает только то, что проверено grep'ом по ВСЕМУ репозиторию
# ВКЛЮЧАЯ archive/ (кроме wave/, куда входить нельзя). Настоящий мёртвый код
# (ноль вызовов где угодно) — УДАЛЯТЬ, а не вписывать сюда: так уже разошлись
# hz_sw_dirsum (удалён 07-10), pg924_hash и tri_trace_on.
